# 🏆 OverKill: Ultimate Engagement & Economy Bot

OverKill is a state-of-the-art Discord system designed to drive community activity through a robust economy, automated awards, and an intuitive management suite.

---

## 👤 Member Commands
Essential tools for community participation:

*   **/bank**: Access your personal bank account to claim **Daily Rewards**, build your 🔥 **Streak**, and track your detailed transaction history.
*   **/inventory**: View and manage your personal collection of items and name colors.
*   **/quest**: Real-time dashboard to track your current daily missions and progress.
*   **/trade**: Initiate a secure peer-to-peer trade with another member.
*   **Shop Interaction**: Use simple **[ Buy ]** buttons in dedicated channels to purchase roles, items, and seasonal packs.

---

## 🛠️ Manager Control Panel: `/settings`
The centralized ⚙️ **Control Panel** allows administrators to manage every aspect of the bot from a unified grid interface.

### 💎 Core Modules
*   **Coins & Rewards**: Configure global reward rates, **Server Booster** multipliers, and login streak bonuses.
*   **MVP Automation**: Automatically reward top active users with roles and coins. Feature includes live **📊 Progress** tracking and **🪙 Reward** amount configuration.
*   **Shop Setup**: Create items, organize categories, and **📤 Post** items to buy-channels with ease.
*   **Leaderboards**: Link live rankings for **Activity**, **Wealth**, or **Streaks** to any channel and force-refresh standings.
*   **Audit Logs**: Route server events, financial logs, and administrative actions to dedicated monitoring channels.
*   **User Management**: Directly audit user data to **Modify Balances** or **Edit Inventories**.
*   **Economy Stats**: Overview of server-wide wealth distribution and financial health.
*   **Color Manager**: Add and manage role-based name colors for your community.

---

## 🔋 Mass Operations
Designed for high-volume server management:
*   **/mass item**: Bulk populate Shop Packs or Categories with roles.
*   **/mass color**: Bulk add or remove color roles from the system.

---

### 🕹️ Unified UI Standard
OverKill utilizes a standardized interface across all menus. Every module features consistent **Enable/Disable** toggles and predictable navigation, ensuring the bot is as easy to manage as it is to use.

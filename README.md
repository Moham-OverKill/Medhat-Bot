# 🏆 OverKill Bot: Command & Button Guide

This guide explains how to interact with the OverKill bot using commands and buttons.

---

## 🏦 Personal Dashboard: `/bank`
This is your main hub. When you run `/bank`, you will see these buttons:

*   **[ 🎁 Daily ]**: Claim your daily reward. Checking in every day increases your **Streak Bonus**.
*   **[ 🎒 Inventory ]**: View all items you own.
    *   **[ ⬅️ / ➡️ ]**: Navigate through your items.
    *   **[ 👕 Equip ]**: Activate a role or item (like a name color).
    *   **[ 👕 Unequip ]**: Deactivate the item.
    *   **[ 💰 Sell ]**: Sell the item back to the server for a 50% refund.
*   **[ 💸 Transfer ]**: Send coins to another member. Follow the on-screen prompts to enter the amount and user.
*   **[ 📜 History ]**: See every transaction (earnings and spending) linked to your account.

---

## 🛒 Shopping: Buy Buttons
In the server's shop channels, items are posted with a **[ 💰 Buy ]** button.

1.  Click **[ 💰 Buy ]** to purchase the item.
2.  The coins will be deducted from your bank automatically.
3.  If the item is a **Permanent Item**, it goes to your **Inventory** (Equip it via `/bank`).
4.  If the item is a **Temporary Item**, it is equipped automatically and will expire after a set time.

---

## 🎯 Daily Missions
Special tasks are posted in the missions channel.

*   **Task**: Shows what you need to do (e.g., `Join for 15 minutes`).
*   **Reward**: Shows how many coins you will earn upon completion.
*   **Countdown**: Shows exactly how much time is left before the mission resets.

---

## 🛠️ Admin Commands: `/setup`
Admins can manage the bot using these control panels:

### 1. `/shop setup`
Manage the economy and items.
*   **[ ➕ Add ]**: Create new Items, Categories, or Packs.
*   **[ ✏️ Edit ]**: Change prices, names, or roles of existing items.
*   **[ 🗑️ Delete ]**: Remove items from the shop.
*   **[ 📤 Post ]**: Send an item to a channel so users can buy it.

### 2. `/mvp setup`
Configure automated rewards.
*   **[ 🎭 Role ]**: Set which role is given to top active users.
*   **[ 📢 Channel ]**: Set where the winners are announced.
*   **[ ⏰ Schedule ]**: Set how often the bot awards MVPs (Hourly, Daily, etc.).
*   **[ 🧪 Test ]**: Run a fake rotation to see if settings are correct.

### 3. `/rewards setup`
Set the global reward rates.
*   **MVP Reward**: How many coins winners get.
*   **Booster Multiplier**: Bonus rate for Server Boosters (e.g., 2x).
*   **Streak Bonus**: Coins added per day of your daily streak.

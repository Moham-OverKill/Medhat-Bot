# 🏆 OverKill Bot

OverKill is a premium Discord bot featuring a dynamic economy, automated rewards, and streamlined server management.

---

## 🎮 Commands Guide

*   **/bank**: Access your personal bank account.
*   **/inventory**: View your inventory.
*   **/mass color**: Bulk add or remove color roles.
*   **/mass item**: Bulk populate Shop Packs or Categories with Items.
*   **/quest**: View your current daily quests and progress.
*   **/settings**: Open the server control panel.
*   **/trade**: Initiate a P2P trade with another member.

---

### 🕹️ Unified Interface
All configuration menus are standardized with simple **Enable/Disable** buttons and instant navigation for a smooth experience.
